Jerry Luxury - website
======================
Open the folder in VS Code, then open index.html in a browser
(or use the "Live Server" extension: right-click index.html > Open with Live Server).

Structure
  index.html        page content
  css/style.css     all styling (colours are variables at the top, in :root)
  js/main.js        menu, video, lightbox, testimonials, form
  assets/images     lookbook photos and video poster
  assets/video      hero video (hero.mp4)

Edit contact details in index.html: search for "0707 840 7308" and "lilmarvelmedia@gmail.com".
Fonts load from Google Fonts, so an internet connection is needed for the custom fonts.
